# Security / 安全与隐私

Do not post pairing records, private keys, device identifiers, personal location history, or unredacted device logs in public issues or pull requests. Runtime state belongs in the ignored .state/ directory.

For a security issue, use GitHub's private vulnerability reporting if available. If it is unavailable, open an issue containing only a generic request for a private reporting channel; do not include exploit details or sensitive data. There is no guaranteed response time or supported-version security SLA.

Do not disable endpoint protection, change device privacy settings automatically, or upload credentials to diagnose connection errors.

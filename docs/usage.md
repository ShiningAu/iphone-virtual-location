# 详细使用指南

[English](usage.en.md) · [返回首页](../README.md)

这里的“发送位置”指电脑通过 USB 向自己的 iPhone 发送模拟经纬度，不是上传手机文件或备份。

## 1. 使用前：先准备手机与电脑

1. 电脑准备 Python 3.12 和 Apple Devices 或 iTunes 的 USB 驱动。首次运行项目根目录的 `scripts/setup.ps1` 安装固定依赖。
2. 使用支持数据传输的 USB 线连接手机，解锁 iPhone，在手机上确认“信任此电脑”。密码或信任提示由机主自己完成。
3. **发送坐标之前，先在手机上开启开发者模式**：设置 → 隐私与安全性 → 开发者模式 → 打开。按系统提示重启手机，重启后再次解锁并确认启用。
4. 开启开发者模式后保持手机连接；若重启导致连接中断，重新插接 USB。建议首次只连接一台 iPhone。
5. 如果没有开发者模式入口，或开发者镜像/隧道报错，查看 [故障排查](troubleshooting.md)。本工具不会自动替你开关手机的隐私设置。

## 2. 在电脑发送模拟位置

在项目根目录打开 PowerShell：

```powershell
# 首次安装；已装好可跳过
.\scripts\setup.ps1

# 发送纽约曼哈顿坐标
.\scripts\start.ps1
```

看到 `Sent coordinates` 和等待 Enter 的提示后，**保持窗口运行、USB 连接，不要按 Enter**。这只表示调用已完成，下一步仍需在手机地图验收。若出现连接错误，先解决错误，不要当成已经定位成功。

```powershell
# 香港中环预设
.\scripts\start.ps1 -Preset hong-kong

# 自定义经纬度
.\.venv\Scripts\python.exe .\src\iphone_location.py start --lat 40.7128 --lon -74.0060
```

## 3. 发送后：在手机刷新并确认位置

1. 打开 Apple 地图，点击定位箭头，检查蓝点是否在选定的城市。
2. 如果没有更新，在手机的“设置 → 隐私与安全性 → 定位服务”关闭定位服务，**等待 10 秒，再重新开启**。
3. 回到 Apple 地图，再点定位箭头确认蓝点。这是本次成功案例中使用过的刷新步骤；不保证每台设备都必须或都有效。
4. 若仍未更新，可尝试下面的网络刷新，然后再次检查。全程保持 USB 与电脑上的会话运行。

### 可选：短暂关闭网络后恢复

这是地图不更新时的排查选项，**本次案例没有证实关闭网络是必要条件**，也没有证实它可以解除任何地区限制。

1. 在手机“设置 → Wi-Fi”暂时关闭 Wi-Fi。
2. 在“设置 → 蜂窝网络”暂时关闭蜂窝数据。
3. 在“设置 → 隐私与安全性 → 定位服务”暂时关闭定位服务。
4. 等待约 10 秒后，重新开启定位服务，并把 Wi-Fi、蜂窝数据恢复到操作前的状态。
5. 回到 Apple 地图点定位箭头核实。短暂断网可能中断当前网络活动；不要把网络或定位服务一直关着。

本工具的定位通道是 USB，不需要蓝牙配对。关闭网络不是更换 IP 地址，地图显示新坐标也不证明其他应用的地区资格已改变。

## 4. 使用期间和重新连接

- 保持 USB 与电脑启动窗口运行。定位刷新后，可在目标应用内自行检查所需场景。
- 拔线或重新启动电脑后，不要假定会话仍在；重新连接、解锁，必要时确认信任，再运行启动脚本。
- 两个目标城市之间切换时，先结束原会话，再重新启动所需预设，避免多个模拟会话竞争。
- 只有看到 Apple 地图蓝点实际改变，才能记录为地图验证成功。

## 5. 停止并恢复真实位置

1. 在原启动窗口按 **Enter**，请求结束模拟并清除。
2. 窗口异常退出或不确定清除是否完成时，在原会话停止后执行：

   ```powershell
   .\scripts\restore.ps1
   ```

3. 确认手机定位服务已开启，网络设置已恢复，再打开地图点定位箭头检查。
4. 如果仍显示模拟位置，**重启 iPhone**，解锁后再次检查地图。本次案例实际通过重启后用户查看地图确认真实位置恢复。
5. 不要把“清除命令成功返回”当作“真实位置已恢复”。若重启后仍异常，应停止测试并排查。

## 检查表

| 阶段 | 应确认的状态 |
| --- | --- |
| 发送前 | 开发者模式启用、手机解锁并信任电脑、USB 可传输数据 |
| 发送后 | 电脑会话保持运行；必要时定位服务关 10 秒再开 |
| 可选排查 | 短暂关闭 Wi-Fi/蜂窝数据/定位服务后恢复，不作为必需条件 |
| 使用成功 | 用户在手机地图确认目标城市蓝点 |
| 测试结束 | 停止会话、请求清除、恢复网络和定位服务、地图确认真实位置 |

与健康功能有关的地区限制在本次测试中没有解除，详见 [案例记录](case-study-2026-10-17.md)。

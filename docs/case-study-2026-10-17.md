# 2026-10-17：Windows 经 USB 修改 iPhone 虚拟位置

记录日期采用 Asia/Shanghai。资料来自当日操作会话及用户在手机上的反馈；未采集定位服务内部遥测。

## 过程与结果

1. 通过电脑现有 USBMux 服务读取设备型号与系统版本。
2. 建立独立 Python 环境，安装通信库，并确认开发者模式状态为启用。
3. 建立本地 userspace 开发者隧道，调用 DVT 模拟定位。
4. 将会话等待改成在线程中等待按键，避免阻塞异步隧道；配合手机端定位服务关闭 10 秒后重开，用户确认香港中环定位成功。
5. 切换纽约坐标，用户确认地图到达美国曼哈顿。
6. 分别测试相关健康功能，仍提示地区不可用，没有成功开通。
7. 结束模拟并请求清除后，地图仍保留模拟位置；用户重启 iPhone 后，确认真实位置恢复。
8. 此后重新连接手机，可再次建立会话发送纽约坐标。不能将“命令成功返回”扩大描述为每次均已完成手机端地图确认。

## 整理后的代码与原会话差异

原会话使用临时 CLI 入口和本地依赖文件修改。本仓库改为统一入口、进程内命令回调替换、公共坐标预设、独立安装脚本和退出清除逻辑。自动检查验证参数与会话逻辑；本次整理未为测试新封装而中断现有定位会话，也未将其宣称为已经重新完成全套真机验收。
